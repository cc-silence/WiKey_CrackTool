# WiKey 跑包工具

Windows 桌面软件，为 [hashcat](https://hashcat.net/hashcat/) 的跑包能力提供图形界面：
导入无线握手数据包，用显卡（CUDA / OpenCL）或 CPU 跑字典，输出跑包记录，并附带一套
字典去重与整理工具。

**当前仅支持 Windows。**

---

## 下载

请到 [Releases](../../releases) 页面下载最新版本，下载后直接解压运行
`WiKey跑包工具.exe` 即可，无需安装。

解压包内已包含 hashcat 引擎与 7-Zip，无需另行下载。

## 功能

### 跑包

- **握手包导入**：支持 `.cap`、`.pcap`、`.pcapng`、`.22000`、`.hc22000`、`.hccapx`，
  也支持 `.pcapng-数字` 形式（如 `.pcapng-12`）。
- **自动判重**：导入时自动过滤重复数据包，以及跑包记录中已经跑过的包。
- **分组**：拖入文件夹时按文件夹名自动创建分组，便于按来源整理信号。
- **字典预设**：可自建多套预设分别存放不同字典（例如预设 1 放常用字典、预设 2 放手机
  号码、预设 3 放大字典），跑包时直接选择要用哪几套，无需手动增删字典。
- **逐轮跑包**：按预设顺序推进，所有信号跑完预设 1 再跑预设 2，优先消耗低成本字典。
- **GPU 批量跑包**：多显卡并行，同时处理多个小字典与多个信号。极小的字典自动改用
  CPU，避免 GPU 准备时间反而更慢。
- **定时休息**：可设置连续工作一段时间后自动休息再继续（默认关闭；默认间隔 30 分钟、
  休息 5 分钟）。这是给笔记本减轻长时间高负荷用的定时休息，不是硬件过热保护。
- **完成后操作**：跑完全部任务可选择睡眠或关机。

### 跑包记录

只收录已完整结束的任务：跑完但未出密码的信号，以及已确认跑出密码的信号。中途取消、
失败和未跑完预设的信号不会被误记为完成。

### 字典工具

- **多文件自动去重**：多个字典一起处理，交叉比对去掉重复的密码。
- **过滤去重**：按位数限制、含中文字符等条件剔除不需要的密码。
- **字典拆分**：按文件大小或条目数量拆分。
- **字典合并**：把碎字典合并，避免跑包时反复加载准备占用时间。

> 经常跑包的话建议先把字典去重：11 GB 的字典去重后通常能降到 6 GB 左右，差不多省一半
> 跑包时间。

### 常规设置

日志导出、界面缩放与深浅主题等设置。

## 使用须知

- 软件会把配置与任务数据保存在本机，**不会**上传到任何服务器。
- 诊断日志保存在 `%TEMP%\CrackTool\diagnostics`，软件启动时会自动清理其中超过 30 天的
  旧日志；如需导出请使用日志导出功能。
- 显卡驱动、CUDA / OpenCL 环境差异可能影响实际速度与兼容性，异常时请先用软件内的
  硬件检测与诊断功能查看。
